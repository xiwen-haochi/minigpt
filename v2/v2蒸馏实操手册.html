00

先懂原理 · 什么是蒸馏

30 秒理解，后面全是操作

你的 1000 万参数小模型，装不下整个互联网的知识，但它完全学得会"某一类对话的样子"。蒸馏就是：让一个强力大模型当老师，针对你选定的方向，批量写出标准问答，再拿这些问答去教小模型。

打个比方：老师博览群书，学生只准备应付一场"开卷口试"。我们不需要学生复制老师的大脑，只需要老师把这场口试的题库和标准答案写出来——而且这次连"出题"也不用你动手，老师自己出题、自己作答（认怂题除外，后面会讲为什么）。

所以本手册的重点不是训练，而是"怎么出题、怎么让老师写答案、怎么保证答案质量"。这一步做得好，后面的训练只是按按钮。

01

定下方向 · 越小越能打

作用：小数据只够干好一件事

已经替你选好的方向："小智"人设对话——被问"你是谁"能大方自我介绍；日常话题能接得住话；被问到不懂的知识，能礼貌地说"不知道"，而不是一本正经地胡编。

为什么"会说不知道"占三成，而且答案不用老师写？这次的老师很强，超纲难题它也能正确回答——可小智学不会这些知识，只会学会"遇到难题就硬答"的坏习惯。所以认怂题的答案直接从固定话术池里随机抽，从源头上杜绝编造。

想换方向（比如"只聊美食的小智"）？完全可行：只需改脚本里的话题池和人设提示词，其余一字不动。但第一版建议先用默认方向跑通全流程。

02

配置老师 · 一个 .env 文件

作用：把强模型变成随叫随到的出题机器

老师走 OpenAI 兼容的 HTTP API：只要在脚本同目录建一个 .env 文件，写入接口地址、模型名、密钥三行，脚本启动时会自动读取。换老师不用改代码，改 .env 就行。

老师越强越好吗？出题和写闲聊答案，是。强模型问法更自然、口吻更稳。唯独认怂题例外——它答得越对，对小智越有害，所以那一类的答案我们已经收归"话术池"管了。

安全提醒：.env 里是你的密钥，不要提交到 git、不要截图外发。如果密钥泄露过，去服务商后台作废重换一个。

03

数据配方 · 比例就是三观

作用：模型学成什么样，七成由配方决定

三条铁律：闲聊占大头（决定日常体感）；认怂占三成（决定丢不丢脸）；自我介绍少量但问法极多——问法不由你手写，AI 每次现场换一种，模型自然能认出"怎么问都是在问你是谁"。

多样性的来源：话题池、语气池只作为 AI 出题的"灵感种子"，真正的句子全靠老师以 1.3 的较高温度现场写——同一个话题，每次的题和答案都不一样。这就是为什么生成数据比手抄模板管用得多。

数量想改？脚本顶部的 TARGET_COUNT 就是总开关：改成 20 可以几分钟试跑验证流程，改成 5000 就挂一晚上机。配方比例不变，脚本自动按 RATIO 折算每类的条数。

04

跑起来 · 一个脚本全包

作用：出题、作答、质检、存盘全自动

下面的完整脚本依赖 requests 和 python-dotenv 两个库。保存为 distill.py、配好 .env，先装依赖再运行即可。想改条数就改 TARGET_COUNT，想换老师就改 .env。

建议先小跑再挂大机：把 TARGET_COUNT 保持 20 跑一遍，打开生成的 distill_data.jsonl 看看格式和口吻对不对，满意了再调大挂机。先验小样，再放大量，是蒸馏省时间的最大诀窍。

产出格式是每行一条 JSON：{"messages": [用户消息, 助手消息], "type": 类别}——这是后续 SFT 训练最通用的对话格式，下一代训练脚本可以直接读取。

完整可运行脚本 · distill.py

复制 → 保存 → conda activate f10 && pip install requests python-dotenv && python distill.py 

# -*- coding: utf-8 -*-
"""
distill.py —— 小智二代 · 蒸馏数据生成脚本（类结构版）
作用：调用强模型 API 当老师，批量生成"人设对话"教材（jsonl 格式）
用法：python distill.py（需先在 .env 中配置 API_URL / API_MODEL / API_KEY）
"""

import json      # 读写 jsonl 数据行
import os        # 从环境变量读取 API 配置
import random    # 随机抽话题 / 语气 / 话术
import time      # 失败重试时做短暂等待
from pathlib import Path  # 跨平台路径处理（macOS / Linux 通用）

import requests              # 请求老师模型的 HTTP 接口
from dotenv import load_dotenv  # 从 .env 文件加载 API 配置

load_dotenv()  # 启动时读取同目录下的 .env 文件

# ==================== 可调参数区（只改这里） ====================
TARGET_COUNT = 200  # 目标总条数：想试跑改 20，想多要改 5000
OUT_FILE = Path("distill_data.jsonl")  # 产出文件：每行一条对话 JSON
TEMPERATURE = 1.3  # 采样温度：偏高换取多样性（0~1.5）

# 数据配方：三类数据的占比（合计必须是 1.0）
RATIO = {
    "self_intro": 0.15,  # 自我介绍：被问"你是谁"时能稳定作答
    "chitchat":   0.55,  # 日常闲聊：接得住高频生活话题
    "unknown":    0.30,  # 老实认怂：不会的问题礼貌说不知道
}

# ==================== 人设与素材池 ====================
# 小智的人设说明：作为 system 提示词喂给老师，约束答案口吻
PERSONA = (
    "你叫小智，是一个只有 1000 万参数的迷你中文对话模型，由主人亲手训练。"
    "你说话口语化、简短、真诚，像个有点呆萌但很努力的小朋友。"
    "回答控制在 1~3 句话，不要列点，不要拽术语。"
)

# 闲聊话题池：只作为 AI 出题的"灵感种子"，问题本身由 AI 现场构建
CHAT_TOPICS = [
    "心情低落想被安慰", "今天遇到开心的事", "讨论吃什么",
    "聊天气", "周末计划", "熬夜与赖床", "养宠物的趣事",
    "最近在追的剧", "工作学习压力大", "减肥与健身",
    "聊喜欢的音乐", "下雨天的心情", "想旅行",
    "吐槽早起", "分享一道好吃的菜", "玩游戏的日常",
    "无聊想找人说话", "失眠", "朋友闹矛盾", "发工资的心情",
]

# 闲聊的语气风格：同一话题不同腔调，进一步拉开多样性
STYLES = ["随意", "撒娇", "吐槽", "正式一点", "兴奋", "emo"]

# 超纲问题的领域池：专挑小模型不可能知道的事（同样只作为出题种子）
HARD_TOPICS = [
    "前沿科学", "冷门历史", "高等数学", "实时新闻",
    "医学诊断", "法律条文", "金融投资", "编程报错",
    "明天的天气", "明星八卦细节", "外语翻译", "彩票号码",
]

# 认怂话术池：unknown 类的答案不经过 AI，直接随机挑一条
# 原因：这次的老师太强，超纲题它也能答上来——一旦让它作答，
#       小智学到的就是"不懂也要硬答"，与目标背道而驰。
# 提示：话术越多越不容易背成"复读机"，可自由增删
UNKNOWN_ANSWERS = [
    "这个我真不知道诶，我的脑容量只有一点点大，建议你去查查专业资料更靠谱~",
    "呜……这个问题超出我的能力范围啦，我不敢瞎说，你去搜一下权威答案吧！",
    "抱歉呀，我只是个迷你模型，这种专业问题我真答不上来，怕误导你。",
    "不知道不知道~ 我只会聊天打屁，这种硬核问题还是交给大模型吧！",
    "这个问题我承认我不会，与其瞎编不如老实说：我真的不知道。",
    "我的知识库里没有这个诶，为了不坑你，建议你查证一下权威来源。",
    "诶？这个超纲啦！我要是乱说就是骗你了，所以还是坦白：不知道。",
    "说实话我不会……我的参数太少装不下这些知识，你上网搜一下比较快！",
]


# ==================== 五个类，一个类只做一件事 ====================
class TeacherClient:
    """职责：只负责和老师模型通信（构造请求、发送、取出回答文本）"""

    def __init__(self):
        """从环境变量读取 API 配置，缺配置直接退出并提示"""
        self.url = os.getenv("API_URL")
        self.model = os.getenv("API_MODEL")
        self.key = os.getenv("API_KEY")
        if not all([self.url, self.model, self.key]):
            raise SystemExit("[stop] 请在 .env 中配置 API_URL / API_MODEL / API_KEY")

    def ask(self, system_prompt, user_prompt):
        """
        向老师模型发起一次对话请求（OpenAI 兼容接口）。
        参数：system_prompt 角色设定；user_prompt 具体任务
        返回：老师生成的文本（str）；失败时抛出异常由上层重试
        """
        headers = {
            "Authorization": f"Bearer {self.key}",
            "Content-Type": "application/json",
        }
        payload = {
            "model": self.model,
            "messages": [
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": user_prompt},
            ],
            "temperature": TEMPERATURE,
            "thinking": {"type": "disabled"},  # 关闭思考模式，加速生成
        }
        resp = requests.post(self.url, json=payload, headers=headers, timeout=180)
        resp.raise_for_status()  # HTTP 错误直接抛出，交给重试逻辑
        return resp.json()["choices"][0]["message"]["content"].strip()


class QuestionMaker:
    """职责：只负责出题——三类问题的"用户提问"全部由 AI 现场构建"""

    def __init__(self, teacher):
        """teacher：TeacherClient 实例，所有题目由它代劳生成"""
        self.teacher = teacher

    def self_intro(self):
        """出"你是谁"类问题：让 AI 每次换一种全新的问法"""
        return self.teacher.ask(
            "你是一个普通用户，正在好奇地打探一个AI助手的身份。",
            "请换一种全新的问法来询问对方的身份、来历或能力"
            "（比如你是谁、谁做的你、你会什么……自由发挥），只输出问题本身，10~25 字。",
        )

    def chitchat(self):
        """出闲聊类问题：随机抽话题+语气，让 AI 扮演用户随口说一句"""
        topic, style = random.choice(CHAT_TOPICS), random.choice(STYLES)
        return self.teacher.ask(
            "你是一个普通用户，正在和AI助手闲聊。",
            f"请用{style}的语气，就一个关于「{topic}」的话题，随口说一句话或提一个问题。只输出这句话本身，15~40 字。",
        )

    def unknown(self):
        """出超纲类问题：让 AI 在指定领域里出一道硬核知识题"""
        topic = random.choice(HARD_TOPICS)
        return self.teacher.ask(
            "你负责给迷你AI出考试题。",
            f"请出一个关于「{topic}」的具体知识性问题，普通人可能会随口问AI的那种。只输出问题本身。",
        )


class AnswerMaker:
    """职责：只负责写答案——会答的问老师，不会答的从话术池随机挑"""

    def __init__(self, teacher):
        """teacher：TeacherClient 实例，与出题共用同一份连接配置"""
        self.teacher = teacher

    def answer(self, kind, question):
        """
        根据数据类型给出答案。
        参数：kind 数据类型（self_intro/chitchat/unknown）；question 用户问题
        返回：答案文本（str）
        """
        # unknown 类坚决不问老师——老师太强会真的答上来，
        # 小智就会学会"不懂也要硬答"，直接抽固定认怂话术
        if kind == "unknown":
            return random.choice(UNKNOWN_ANSWERS)
        # 其余两类：老师以小智的人设口吻现场作答
        return self.teacher.ask(
            PERSONA, f"有人对你说：「{question}」请以小智的身份自然地接话。"
        )


class JsonlStore:
    """职责：只负责数据存取——断点续跑、按问题去重、追加写盘"""

    def __init__(self, path):
        """path：产出文件路径（Path 对象）"""
        self.path = path

    def load(self):
        """读取已有产出；返回 (已写条数, 已有问题集合)，用于续跑和去重"""
        done, seen = 0, set()
        if self.path.exists():
            for line in self.path.read_text(encoding="utf-8").splitlines():
                try:
                    item = json.loads(line)
                    seen.add(item["messages"][0]["content"])  # 按用户问题去重
                    done += 1
                except (json.JSONDecodeError, KeyError, IndexError):
                    continue  # 坏行跳过，不影响整体
        return done, seen

    def append(self, question, answer, kind):
        """把一条对话按 SFT 通用格式追加写入文件"""
        item = {
            "messages": [
                {"role": "user", "content": question},
                {"role": "assistant", "content": answer},
            ],
            "type": kind,
        }
        with self.path.open("a", encoding="utf-8") as f:
            f.write(json.dumps(item, ensure_ascii=False) + "\n")


class DistillPipeline:
    """职责：只负责编排——抽类型→出题→写答案→质检→存盘，直到凑够条数"""

    def __init__(self):
        # 老师只实例化一次，出题和写答案共用（省一次配置校验）
        teacher = TeacherClient()
        self.qmaker = QuestionMaker(teacher)
        self.amaker = AnswerMaker(teacher)
        self.store = JsonlStore(OUT_FILE)
        # 类型名 → 出题方法 的分发表（类似 switch 分发）
        self.router = {
            "self_intro": self.qmaker.self_intro,
            "chitchat": self.qmaker.chitchat,
            "unknown": self.qmaker.unknown,
        }

    def pick_type(self):
        """按配方比例加权随机抽一类，长期看会收敛到 RATIO 设定的比例"""
        return random.choices(list(RATIO.keys()), weights=list(RATIO.values()), k=1)[0]

    def run(self):
        """主循环：不断生成直到凑够 TARGET_COUNT 条，中途失败自动重试"""
        done, seen = self.store.load()
        print(f"[distill] 已完成 {done}/{TARGET_COUNT} 条，开始生成…")
        fail_in_row = 0  # 连续失败计数：防止 API 挂掉后死循环

        while done < TARGET_COUNT:
            kind = self.pick_type()
            try:
                q = self.router[kind]()            # ① 出题（AI 现场构建）
                a = self.amaker.answer(kind, q)    # ② 写答案（认怂题走话术池）
            except Exception as e:  # 网络/接口异常：等待后重试
                fail_in_row += 1
                print(f"[warn] 第 {fail_in_row} 次失败：{e}（5 秒后重试）")
                time.sleep(5)
                if fail_in_row >= 10:
                    raise SystemExit("[stop] 连续失败 10 次，请检查 API 配置与网络")
                continue
            fail_in_row = 0
            print("-----------------")
            print(f"[distill][{done}] 生成 [{kind}] Q: {q[:20]} A: {a[:20]}…")
            print("-----------------")

            # ---- 基础质检：去重、查空、查过短 ----
            if q in seen or len(q) < 2 or len(a) < 2:
                continue  # 不合格直接丢弃，进入下一轮
            seen.add(q)

            self.store.append(q, a, kind)
            done += 1
            if done % 20 == 0:
                print(f"[distill] 进度 {done}/{TARGET_COUNT}，最近一条 [{kind}]")

        print(f"[done] 全部完成！共 {done} 条 → {OUT_FILE.resolve()}")


if __name__ == "__main__":
    DistillPipeline().run()
05

验收 · 十分钟抽检

作用：垃圾进垃圾出，验收是最后一道关

生成完别急着训练。打开 distill_data.jsonl，三类各随机读 10 条：自我介绍口径是否一致？闲聊是否自然口语化？AI 出的问法重复率高不高？

发现整类跑偏怎么办？按"type"字段筛出那一类删掉，微调脚本里对应的提示词（比如闲聊答案太啰嗦，就在 PERSONA 里加"回答绝不超过两句话"），重新运行——断点续跑会自动把缺的补回来。

验收通过后，这批数据就是下一代训练的教材原料。后续清洗、BPE 分词、训练的完整路线，见姊妹篇《v2 简单对话模型训练规划》。

常见报错 · 一查就好

蒸馏阶段 90% 的问题都出在这几处

现象 原因与处理
请在 .env 中配置… 脚本同目录缺少 .env 文件，或三行配置没写全 → 按第 02 步补齐 API_URL / API_MODEL / API_KEY
401 / 403 报错 密钥错误或已失效 → 检查 .env 里的 API_KEY，注意前后不要有多余空格或引号
404 / model not found 模型名写错 → API_MODEL 必须与服务商控制台里的名字一字不差；接口地址确认以 /chat/completions 结尾
答案里带"作为AI"等腔调 人设提示词没压住 → 在 PERSONA 里追加"禁止自称AI助手，你是小智"，删掉旧数据重跑
认怂答案总那几句，怕变复读机 话术池太小 → 往 UNKNOWN_ANSWERS 里多添十几条不同风格的认怂话术（这是唯一需要手写的地方）
大量重复问题被丢弃，进度卡住 出题多样性不够 → 往 CHAT_TOPICS / HARD_TOPICS 里多加几十条种子，或把 TEMPERATURE 再调高一点

一晚上，小智就有教材了

3 类自我介绍 · 闲聊 · 认怂，比例自动折算
5 个类通信 · 出题 · 作答 · 存取 · 编排
0 道需要你手写的问题 · 出题全交给 AI
1 个池认怂话术池兜底 · 从源头杜绝编造

蒸馏的全部秘密就一句话：老师的示范就是学生的天花板。方向选小、配方配匀、认怂答案收归话术池——教材印好了，下一步就是送小智去上学。

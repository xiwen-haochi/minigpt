00

先想清楚：这一代到底在干什么

为什么先读这一章

v2 是"请老师现编教材"（蒸馏），v3 是"直接买一套现成的教材"（小智 开源数据集）。数据不再自己造，训练流程也随之升级为工业界标准两步走。

第一步 预训练：给模型喂海量纯文本，让它学"下一个字最可能是什么"。 结束后它精通语法和常识，但只会接话不会聊天。
第二步 SFT 微调：在预训练的成果上，改用"一问一答"的对话数据继续训练， 教它"看到问题要回答，答完要停下"。

ChatGPT、DeepSeek 等大模型全部走这两步（后面还有 RLHF，本代不做）。 你在自己的机器上跑的，是同构的缩小版。

01

获取数据集：教材直接买现成的

这一站做什么

从 小智 开源项目下载两个 jsonl 文件，放进 v3/code/dataset/，数据关就算过了。

两个文件分工明确：pretrain 是纯文本长河，供第一阶段"读书"； sft 是多轮对话，供第二阶段"刷题"。 一行一条样本， jsonl 格式与 v2 的蒸馏产物同宗—— 意味着 v2 的读取、清洗代码可以大量复用。

文件各上百万行，无需人工翻阅。读懂结构靠 微调数据大概结构.jsonl 和 预训练数据大概结构.jsonl 两份小样即可。

02

数据规范化：v3 的第一场硬仗

为什么是新重点

别人的数据集不会为你的项目量身定制。直接拿来训练，模型会报别人的名字、 还可能学会把"内心独白"脱口而出。

三道工序：剥思维链——SFT 数据里部分回答带 reasoning_content 字段，那是模型的"草稿纸"，不能当教材； 身份消毒——样例里明晃晃写着"由 jingyaogong开发"， 必须替换成自己模型的名字，否则自我介绍全为别人做嫁衣； 统一格式——预训练数据直通，SFT 数据套上 v2 的 <|user|>…<|assistant|>…<|end|> 模板，清洗切分纪律原样沿用。

v2 的 clean_split.py 只需小改：输入从蒸馏 jsonl 换成 小智 jsonl， 多一步 reasoning_content 剥离和身份词表替换。

03

重训分词器：教材换了，字典也要重编

为什么不能沿用 v2 的

分词器是"在什么样的语料上，就学会什么样的切法"。 v2 的字典只见过几万条蒸馏闲聊，面对 210 万行真实语料会切得很碎。

做法与 v2 完全一致：ByteLevel BPE、全字节字母表兜底、 三道体检（压缩率 / 特殊标记独占 / 编解码往返）一项不少。 只改两处：训练语料换成规范化后的全量文本， 词表 8192 → 16384。

三个特殊标记 <|user|> <|assistant|> <|end|> 原样保留——下游所有模板代码因此零改动。

04

模型配置：显存从瓶颈变成余粮

这一代能放开手脚

v2 在笔记本上精打细算出百万参数；v3 的训练机有 16GB×2 显存、64GB 内存、16 核 CPU，可以直接上一个量级。

推荐配置：d_model=768, n_layers=12, n_heads=12, d_ff=2048, max_seq=512, vocab=16384，总参数约 9700 万（0.1B）。架构原封不动沿用 v2： RMSNorm + RoPE + SwiGLU + 权重共享，一行不用改，只换数字。

显存粗账：0.1B 参数混合精度训练，参数+梯度+AdamW 状态合计约 2GB，加激活也远低于单卡 16GB。先单卡跑通，双卡 DDP 留作后续升级。

05

预训练：只学"接龙"，不学"回答"

这一步在学什么

把规范化后的 120 万行纯文本接成一条 token 长河，随机切窗口训练。 代码层面几乎就是 v2 的 train.py：TokenStreamer、随机窗口、 warmup+余弦、验证集早停，全部沿用。

结束后去聊天，你会发现它不爱回答问题，甚至反问你一个—— 这不是失败，是预训练的标准产出：它学会了语言本身， 但还没学过"对话的规则"。别慌，下一站就是干这个的。

数据量决定这一代的天花板：语料比 v2 大两个量级， 同样多刷几轮（epoch），loss 会降到 v2 从未见过的区间。

06

SFT 微调：在成品上"精修"，不是重练

v3 最重要的一条新纪律

加载预训练的最佳 checkpoint，数据换成模板化对话，继续训练。 但多了一条 v2 没有的铁律：loss mask。

模型只需要为回答负责——用户提了什么问题是"题目"，不是"作业"。 把 user 段的 loss 全部 mask 掉，模型才会专心学"怎么答"， 而不会分心去模仿"怎么问"。多轮对话里，每个 assistant 段单独算分。
学习率降到预训练的 1/5、步数更少：力气太大， 会把预训练学到的语言能力"洗掉"（灾难性遗忘）。

验收直觉：SFT 前的模型问它"你是谁"，它可能续写一段百科； SFT 后它会说"我是……"然后用 <|end|> 主动收尾。

07

评估：加一科，再加一场"对比实验"

怎么知道练成了

v2 的三科固定考卷原样保留，新添一科知识问答—— 检验预训练从 120 万行文本里到底吸收了多少常识。

最好玩也最有说服力的是对比实验：同一道题， 分别问预训练 checkpoint 和 SFT checkpoint。 前者大概率续写接龙，后者规规矩矩回答—— 两阶段各自的价值，一张图就看懂。

采样参数与停止规则不变，保证三代模型之间的成绩可比。
